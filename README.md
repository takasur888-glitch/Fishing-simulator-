# Raft Survival

A mobile-first, side-view 2D ocean fishing and exploration game prototype.

## Current playable build
- Side-view cartoon ocean and raft scene
- Touch joystick for boat steering (keyboard arrows/WASD also work)
- Fixed fishing zones with automatic catches
- Fish inventory with boat-based storage capacity
- Fish rarity, selling at Fish Market Island, XP and level-ups
- Five planned ocean regions with level, boat and rod progression
- Boat shop, rod shop and practical boat upgrades
- Islands with automatic dock proximity and service menus
- Shark encounters and boat damage; at 0 HP the same boat respawns and stored fish are lost
- Region map with paid fast travel between discovered regions
- Missions, coins, bait, weather visuals and local offline save

## Run locally
`npm install` then `npm run dev`.

## Build Android debug APK
1. Open the repository's **Actions** tab.
2. Select **Build Android APK**.
3. Tap **Run workflow** (or wait for a push build).
4. Download the `Raft-Fishing-Survival-debug-apk` artifact when the workflow succeeds.

This is an early playable prototype, not the finished game or a Play Store release.
