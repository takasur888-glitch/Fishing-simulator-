# Raft Fishing Survival

A 2D mobile-first ocean survival game prototype.

## Current prototype
- Starter raft on an animated ocean
- Floating wood, plastic, leaves and barrels to collect
- Fishing with a timed bite-and-catch mechanic
- Hunger, thirst and raft health
- Raft crafting and level upgrades
- Day counter and local save on the device
- Touch-friendly Android layout

## Build an Android APK
1. Open the **Actions** tab in this repository.
2. Select **Build Android APK**.
3. Tap **Run workflow** (or wait for the workflow after a push).
4. When it finishes, open the run and download the artifact named **Raft-Fishing-Survival-debug-apk**.

This first build is a debug APK for testing, not a Play Store release.
