# Raft Survival 3D

This is the new Godot 4 project for the 3D rebuild. The old Vite/Capacitor prototype is kept untouched in the repository root.

## Open on Android
1. Install Godot Engine for Android.
2. Download this repository as a ZIP from GitHub, or clone it with an Android Git client.
3. Extract the ZIP.
4. In Godot, choose Import and select `godot3d/project.godot`.
5. Open the project and press Play.

## Current prototype
- Procedural 3D ocean with animated waves
- 3D raft, deck, storage crate, mast and sail
- Distant tropical island
- Sky, directional sunlight and shadows
- Basic keyboard sailing test controls

This is a first visual foundation, not the finished high-detail game. Next milestones: touch joystick, better hull geometry and textures, fish models, fishing zones, shops, inventory, progression, weather and Android performance settings.

## Mobile performance
The project starts with the Compatibility renderer for broader Android GPU support. High-end visual options should be added as scalable settings and tested on real devices.
